## Daily Buffer Workflow

The [`buffer/`](./buffer) folder serves as your daily inbox for new problem files:

1. **Add new files:** Whenever you solve a problem, save the file directly in the `buffer/` directory (e.g. `invert-binary-tree.py`).
2. **Classify:** When ready, ask Antigravity:
   > *"Classify and organize the files in the buffer folder"*
3. **Auto-sort:** The files will be analyzed by problem type/data structure and moved into their respective category folders automatically.
